테이블 태그는 엑셀의 행열과 같다.

행은 row, 열이 columns -> F열 25행

태그는 뭐가 있었냐면

  1. 테이블 태그로 표를 만든다. border는 나중에 CSS에서 다시~
  2. caption으로 표의 제목을 정한다.
  3. tr로 행을 만든다.
  4. th는 제목, td는 내용
